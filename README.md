# DOROBAKU

## Pengenalan

**DoroBaku** adalah gim puzzle edukasi 2D bergaya *pixel art* yang menantang pemain untuk menyusun kotak huruf menjadi kata baku melalui mekanisme permainan ala *Sokoban*. Gim ini menghadirkan perpaduan antara tantangan logika dan pembelajaran bahasa Indonesia dalam format interaktif.

Dengan mengusung konsep belajar sambil bermain, DoroBaku dirancang agar proses pembelajaran menjadi lebih seru, mudah diingat, dan bebas dari rasa bosan. Gim ini didukung oleh narasi fantasi yang memikat serta desain visual yang ramah anak, sehingga sesuai digunakan sebagai sarana peningkatan literasi sejak dini sekaligus hiburan edukatif berkualitas di perangkat mobile.

## How to Install

1. **Unduh berkas gim**
   - Akses halaman rilis atau repositori resmi DoroBaku.
   - Unduh berkas APK atau paket instalasi yang tersedia.

2. **Instal pada perangkat**
   - Untuk Android, aktifkan izin *Install from Unknown Sources* jika diperlukan.
   - Jalankan berkas instalasi hingga proses selesai.

3. **Jalankan gim**
   - Buka aplikasi **DoroBaku** dari menu perangkat.
   - Gim siap dimainkan.

> Catatan: DoroBaku dikembangkan menggunakan *game engine* Godot dan dioptimalkan untuk perangkat Android.
